# 记忆架构详细说明

## 完整的记忆层级定义

### 第一层：感官记忆层 (Sensory Memory)

**定义**：原始的五感输入，还未经意识加工。

**组成**：
- **视觉记忆** (Iconic Memory) — 看到的画面、颜色、形状
- **听觉记忆** (Echoic Memory) — 听到的声音、音乐、语言
- **嗅觉记忆** (Olfactory Memory) — 闻到的气味
- **味觉记忆** (Gustatory Memory) — 尝到的味道
- **触觉记忆** (Haptic Memory) — 身体感受到的触感、温度、疼痛

**技术参数**：
- 持续时间：100ms ~ 1s（视觉）；1 ~ 5s（听觉）
- 容量：极大，但大部分未经注意即消失
- 过滤机制：注意力筛选（Attention Filter）

**在Agent中的实现**：
- 文本描述转换为感官标签
- 提取感官关键词：颜色、声音、气味、触感、味道
- 计算感官强度指数

---

### 第二层：即时记忆层 (Working Memory / Immediate Memory)

**定义**：当前正在思考的信息，容量有限。

**组成**：
- **当前事件** — "刚才发生了什么"
- **闪现念头** — 脑子里突然出现的想法
- **临时信息** — 电话号码、名字等短期需要的信息

**技术参数**：
- 持续时间：秒 ~ 分钟
- 容量：7 ± 2 个组块（Miller's Law）
- 遗忘率：80-90% 在几分钟内消失

**在Agent中的实现**：
- 提取最鲜明的片段（salient fragments）
- 重要性评分（importance score）
- 未被强化的记忆进入"即将遗忘"状态

---

### 第三层：母记忆层 (Mother Memory / Episodic Core)

**定义**：人生的核心叙事，"我是谁"的故事主线。

**组成**：
- **人生时间线** — 从出生到现在的关键事件
- **情感锚点** — 高光时刻、创伤事件、转折点
- **身份认同核心** — 我是谁、我相信什么、我的价值观

**技术参数**：
- 持续时间：长期甚至永久
- 访问频率：高频
- 情感权重：高情感事件优先保留

**在Agent中的实现**：
- 叙事重组（narrative reconstruction）
- 情感强度标注
- 关键事件标记为"不可遗忘"

---

### 第四层：子集记忆层 (Subset Memories)

从母记忆分解出的具体记忆类别。

#### 4.1 身份记忆 (Identity Memory)
- 核心自我认知
- 人格特质描述
- 自我叙事
- 典型反应模式

#### 4.2 事实知识 (Factual Knowledge)
- 客观信息记忆
- 具体事件的时间地点
- 学到的知识
- 可陈述的事实

#### 4.3 关系记忆 (Relational Memory)
- 与他人的关系故事
- 重要的他人（important others）
- 关系中的关键时刻
- 对他人的情感态度

#### 4.4 情感记忆 (Emotional Memory)
- 强烈情绪经历
- 情感模式
- 情绪触发点
- 情感反应倾向

#### 4.5 技能记忆 (Skill Memory)
- 会做的事情
- 学会的过程
- 身体记忆（肌肉记忆）
- 习惯性行为

#### 4.6 遗忘区 (Forgotten Zone)
- 已经模糊的记忆
- 细节丢失的记忆
- 偶尔会被唤起的碎片
- "好像有这件事但不记得细节"

```
              ↓                       ↓                       ↓
        事实知识                技能记忆                遗忘区
```

## 遗忘机制

### 遗忘的三种模式

1. **自然遗忘 (Natural Decay)**
   - 时间越长，记忆越模糊
   - 公式：`strength = initial_strength * (decay_rate ^ time)`

2. **干扰遗忘 (Interference)**
   - 新记忆覆盖旧记忆
   - 相似事件之间互相干扰

3. **动机性遗忘 (Motivated Forgetting)**
   - 有意回避痛苦记忆
   - 情感防御机制

### 遗忘的影响因素

| 因素 | 对记忆的影响 |
|------|-------------|
| 情感强度 | 高 → 更难忘 |
| 重复次数 | 多 → 更难遗忘 |
| 关联数量 | 多 → 更难遗忘 |
| 时间 | 久 → 更易遗忘 |
| 睡眠 | 有 → 巩固记忆 |

## 在Agent中的实现考虑

1. **存储格式**：自然语言 + 结构化标签
2. **检索机制**：基于重要性和相关性的动态检索
3. **更新机制**：每次"经历"后更新记忆权重
4. **遗忘模拟**：基于时间衰减和重要性评分
