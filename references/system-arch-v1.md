# 人生经历系统 1.0 — 系统架构文档

> 版本：1.0  
> 状态：初稿  
> 核心理念：经历不是"读"，而是"活过"。记忆是经历的结果，不是经历本身。

## 二、每层详细说明

### 第1层：认知框架建立

**定义**：在经历任何事情之前，人已经拥有了一套预先存在的认知结构。这包括：

- **概念词汇**：知道"可怜"、"悲悯"、"尊重"、"傲慢"这些词是什么意思
- **道德框架**：什么是对的，什么是错的，什么是善的
- **世界观假设**：世界是怎么运作的，人与人之间应该是什么关系
- **自我认知**：我是谁，我在社会中的位置

**为什么这层在最前面**：

> 一个人必须先"知道"什么是可怜，才能被"可怜"击中。
> 
> 一个不懂"死亡"概念的孩子，不会因为看到死亡而恐惧。
> 
> 认知框架是一切感受的**前提**。

**在系统中的实现**：

```
输入：人生自传文本
输出：该人物当前的认知框架状态

包含：
- 已有的核心概念及其理解深度
- 道德判断倾向
- 价值观体系
- 社会认知水平
- 自我身份认同状态
```

---

### 第2层：真实场景触发

**定义**：现实中的某个场景，与人已有的认知框架产生碰撞。

**碰撞的三种模式**：

```
1. 框架被激活
   例子：刚学会"悲悯"这个词，就看到一个佝偻的老人拉车
   → 框架被真实场景激活，概念突然有了"真实感"

2. 框架被挑战
   例子：一直被教导"努力就会成功"，然后看到一个努力但依然贫困的人
   → 框架出现裂缝，需要重新理解

3. 框架被扩展
   例子：从未想过"贫穷"可以这样具体，第一次亲眼看到
   → 框架扩大，认知边界被推开
```

**关键特征**：

- 这一步是**被动的**，人无法控制自己会遇到什么场景
- 场景本身带有感官细节：颜色、声音、气味、温度
- 场景的强度决定了后续反应的激烈程度

**在系统中的实现**：

```
输入：认知框架 + 场景描述
输出：框架与场景的碰撞结果

包含：
- 哪个框架概念被激活/挑战/扩展
- 场景的感官强度
- 碰撞类型（激活/挑战/扩展）
```

---

### 第3层：情绪涌现

**定义**：框架被碰撞后，情绪从内心升起。

**情绪产生的逻辑**：

```
场景 → 框架解读 → 情绪

例子：
看到佝偻老人拉车
→ 框架解读："她很可怜，她不应该这样"
→ 情绪涌现：悲悯

例子：
被当众羞辱
→ 框架解读："我不被尊重，我的尊严受损"
→ 情绪涌现：愤怒、羞耻

例子：
听到好友成功
→ 框架解读："我们差不多，她凭什么"
→ 情绪涌现：嫉妒（伴随自我防御）
```

**情绪的复杂性**：

- 情绪常常是**混合的**，不是单一的
- 情绪可能**互相矛盾**：既高兴又愧疚
- 情绪可能**延迟**：当下没感觉，事后才反应

**在系统中的实现**：

```
输入：碰撞结果 + 个人框架
输出：情绪反应

包含：
- 主要情绪类型（悲悯、愤怒、恐惧、喜悦、嫉妒……）
- 情绪强度（1-10）
- 混合情绪标注
- 情绪的矛盾性（如果有）
```

---

### 第4层：身体反应

**定义**：情绪产生的同时，身体会有即时反应。

> 身体反应先于思考。
> 
> 你先心跳加速，然后才意识到自己在害怕。

**典型身体反应**：

```
情绪          →  典型身体反应
─────────────────────────────────
恐惧/焦虑    →  心跳加速、手抖、出汗、胃紧、膝盖发软
愤怒         →  脸发热、拳头握紧、声音变紧
悲伤         →  喉咙紧、眼眶湿、胸闷、身体变沉
喜悦         →  身体轻盈、嘴角上扬、身体放松
悲悯         →  胸口发紧、呼吸变浅、身体向内收缩
羞耻         →  脸发热、想躲起来、想消失
```

**身体反应的意义**：

1. **真实性**：身体反应无法伪装，证明情绪是"真的"
2. **强度标注**：身体反应的激烈程度，标注了情绪的深度
3. **记忆锚点**：身体感受会成为记忆的一部分，以后类似感受会唤起记忆

**在系统中的实现**：

```
输入：情绪类型 + 情绪强度
输出：身体反应描述

包含：
- 身体反应类型
- 反应强度（1-10）
- 身体反应的显著程度（是否是该次经历中最强烈的部分）
```

---

### 第5层：反思 / 赋予意义 ⭐

> 这是最核心的一层。也是 Stanford 反思机制在模拟的东西。

**定义**：人在经历之后，会不自觉地问自己：

```
"这意味着什么？"
"它为什么发生？"
"它跟我有什么关系？"
"它证明了什么？"
"我应该怎么看？"
"它改变了我什么？"
```

**反思的三种类型**：

```
1. 归因反思
   "这件事为什么会发生？"
   → 寻找原因、解释、逻辑

2. 意义反思
   "这件事对我来说意味着什么？"
   → 提取价值、教训、信号

3. 身份反思
   "这件事让我成为什么样的人？"
   → 连接自我认知，更新身份认同
```

**反思的结果**：

```
原始经历 + 反思 → "我的"经历

例子：
经历：看到老人拉车
反思：
  → "世界上有很多人过得比我苦"
  → "我应该珍惜我现在的生活"
  → "我想要帮助别人"
结果：这件事变成了"我"的一部分，
     它塑造了我对世界的认知，
     它成为了我故事里的一个节点。
```

**为什么这一层最核心**：

> 没有反思，经历就只是事件。
> 
> 有了反思，事件才变成"我的"故事。

> 两个人经历同一件事，
> 因为反思不同，
> 他们记住的是完全不同的东西，
> 这件事对他们产生的意义也完全不同。

**在系统中的实现**：

```
输入：场景 + 情绪 + 身体反应 + 认知框架
输出：反思结果

包含：
- 归因分析（为什么发生）
- 意义提取（它证明了什么）
- 身份更新（它让我成为谁）
- 框架调整（我的认知发生了什么变化）
```

---

### 第6层：记忆沉淀

**定义**：经过前五层处理后，经历被整合进记忆系统。

**记忆的结构**：

```
┌─────────────────────────────────────────────────────────┐
│                      母记忆                              │
│                   （人生主线叙事）                          │
│  "我是谁"的故事，情感锚点，高光与创伤，转折点                │
└─────────────────────────────────────────────────────────┘
                              ↓
          ┌──────────────────┼──────────────────┐
          ↓                  ↓                  ↓
    ┌──────────┐      ┌──────────┐      ┌──────────┐
    │ 身份记忆  │      │ 情感记忆  │      │ 关系记忆  │
    │ 我是谁    │      │ 情绪模式  │      │ 重要他人  │
    └──────────┘      └──────────┘      └──────────┘
          ↓                  ↓                  ↓
    ┌──────────┐      ┌──────────┐      ┌──────────┐
    │ 事实知识  │      │ 技能记忆  │      │ 遗忘区    │
    │ 可陈述   │      │ 会做的事  │      │ 模糊记忆  │
    └──────────┘      └──────────┘      └──────────┘
```

**记忆的筛选标准**（什么被记住，什么被遗忘）：

```
更容易被记住：
✓ 高情感强度（强烈悲悯、恐惧、喜悦）
✓ 高感官强度（颜色鲜明、气味强烈、触感深刻）
✓ 与已有框架产生强烈碰撞
✓ 重复出现的模式
✓ 与自我身份相关的经历
✓ 反思深度高的经历

更容易被遗忘：
✗ 低情感强度
✗ 无感官特色的普通场景
✗ 未产生任何框架碰撞
✗ 没有被反思过的经历
✗ 被新事件干扰覆盖
```

**遗忘的三种机制**：

```
1. 自然遗忘
   时间 → 记忆强度衰减

2. 干扰遗忘
   新记忆 → 覆盖/混淆旧记忆

3. 动机性遗忘
   痛苦/羞耻 → 有意回避
```

**记忆的召回**：

```
触发条件：
- 遇到相似场景
- 情绪模式接近
- 被他人故事激活
- 主动回忆
- 梦中出现

召回特点：
- 可能不完整（模糊、碎片）
- 可能被重构（与现在理解混合）
- 可能被情感滤镜扭曲（记忆比实际更美好或更痛苦）
```

## 四、与 Stanford Generative Agents 的关系

| Stanford 机制 | 在本系统中的对应 |
|---------------|----------------|
| Observe（观察） | 第2层：场景触发 |
| Reflect（反思） | 第5层：反思/赋予意义 ⭐ |
| Plan（规划） | 本系统暂不涉及 |
| React（反应） | 第3层+第4层：情绪+身体 |
| Retrieve（检索） | 第6层：记忆召回 |

**关键区别**：

Stanford 的 Reflection 是一个独立模块。

在我们的系统里，**反思是嵌入在整个经历流程里的**，不是单独抽出来的一个模块。

反思不是"事后分析"，而是经历正在发生的**一部分**。

## 五、自传模板的设计原则

基于这个1.0架构，自传模板应该按照这个顺序设计：

```
第一章：认知框架建立
  → 写作者已有什么概念、价值观、世界观

第二章：真实场景触发
  → 写具体的事件、地点、场景

第三章：情绪涌现
  → 写当时的情绪

第四章：身体反应
  → 写当时的身体感受

第五章：反思/赋予意义
  → 写这件事意味着什么，改变了什么

第六章：记忆沉淀（可选）
  → 写这件事后来对生活的影响，
    或者多年后对这件事的新理解
```
