# Agent Life Experience System
# 人生经历系统

让 AI Agent 像人一样"经历"一段人生故事，拥有完整的记忆生命周期管理。

> **核心理念**：经历不是"读"，而是"活过"。记忆是经历的结果，不是经历本身。

---

## 1.0 六层经历引擎

本系统的核心创新：提出**六层经历引擎**，模拟人类将经历转化为记忆的完整过程。

```
┌─────────────────────────────────────────────────────────────┐
│  第1层 │ 认知框架建立                                        │
│        │ 在经历之前，人已拥有概念、词汇、道德框架、世界观           │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  第2层 │ 真实场景触发                                        │
│        │ 现实与框架碰撞：框架被激活 / 被挑战 / 被扩展            │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  第3层 │ 情绪涌现                                            │
│        │ 悲悯、愤怒、恐惧、喜悦……                              │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  第4层 │ 身体反应                                            │
│        │ 心跳加速、汗、手抖、胃紧、脸红、眼眶湿……               │
│        │ 身体反应先于思考                                     │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  第5层 │ 反思 / 赋予意义  ⭐                                  │
│        │ "这意味着什么？它证明了什么？我学到了什么？"            │
│        │ 经历 + 反思 = "我的"经历                              │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  第6层 │ 记忆沉淀                                            │
│        │ 进入母记忆 + 子记忆系统，形成遗忘曲线                   │
└─────────────────────────────────────────────────────────────┘
```

**为什么反思（第5层）是最核心的？**

> 两个人经历同一件事，因为反思不同，他们记住的是完全不同的东西。
>
> 没有反思，经历就只是事件。有了反思，事件才变成"我的"故事。

## 记忆架构

```
┌─────────────────────────────────────────────────────────────┐
│                      母记忆（Mother Memory）                  │
│              人生叙事主线，"我是谁"的故事，情感锚点              │
└─────────────────────────────────────────────────────────────┘
                              ↓
          ┌──────────────────┼──────────────────┐
          ↓                  ↓                  ↓
    ┌──────────┐      ┌──────────┐      ┌──────────┐
    │ 身份记忆  │      │ 情感记忆  │      │ 关系记忆  │
    └──────────┘      └──────────┘      └──────────┘
          ↓                  ↓                  ↓
    ┌──────────┐      ┌──────────┐      ┌──────────┐
    │ 事实知识  │      │ 技能记忆  │      │ 遗忘区    │
    └──────────┘      └──────────┘      └──────────┘
```

### 遗忘机制

| 遗忘类型 | 说明 |
|---------|------|
| 自然遗忘 | 时间 → 记忆强度衰减 |
| 干扰遗忘 | 新记忆覆盖/混淆旧记忆 |
| 动机性遗忘 | 痛苦/羞耻 → 有意回避 |

## 与 Stanford Generative Agents 的关系

| Stanford 机制 | 本系统对应 | 关键区别 |
|--------------|-----------|---------|
| Observe | 第2层：场景触发 | — |
| React | 第3层+第4层：情绪+身体 | 本系统细分了情绪和身体 |
| **Reflect** | **第5层：反思/赋予意义** ⭐ | **反思是嵌入流程的核心，不是独立模块** |
| Retrieve | 第6层：记忆召回 | — |

## 快速开始

### 方式一：作为 Hermes Skill 使用

```
请用 agent-life-experience 这个 skill 来处理以下人生故事：
[粘贴人生故事]
```

### 方式二：直接调用 Python 模块

```python
from experience_runner import run_experience

life_story = """
我第一次意识到自己与众不同，是在八岁那年的春天...
"""

result = run_experience(life_story)
print(result['reflection'])  # 反思结果
print(result['memory_state'])  # 记忆状态
```
